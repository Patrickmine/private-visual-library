# 私人图像参考图库

把本地图片整理成固定样式、方便筛选的私人参考图库。

提供图片文件夹 → Agent 逐张看图分类 → 用户确认品类 → 生成并打开图库。

## 能做什么

- 按品类、图片类型、构图和背景整理图片，支持组合筛选、单图查看和翻页。
- 无法确定品类时，集中列出完整原文件名，方便补充或保留为“未指定品类”。
- 新图库另存并包含图片副本，原图保持不变。
- 保存用户的品类修正；生成新版时，可继承同名且内容未变的图片修正。
- 重新打开已有图库，无需重新分类或生成。

## 安装和使用

在 Codex 中提供以下请求，让 Agent 安装：

```text
请安装这个 GitHub 仓库里的 Skill：
https://github.com/Patrickmine/private-visual-library
```

安装后调用：

```text
使用 $private-visual-library，把这个文件夹的图片整理成私人图库：
【填写图片文件夹位置】
```

Agent 会先展示品类清单供你确认，再生成并打开。需要你提供信息或确认时，会用彩色符号和加粗提示。

已有图库可以这样重新打开：

```text
使用 $private-visual-library，重新打开已有图库：
【填写图库文件夹位置】
```

## 使用条件

- 需要能够读取本地图片、操作文件并运行 Python 的 Agent；核心脚本使用 Python 3.9+ 标准库。
- 支持 PNG、JPEG 和静态 WebP。异常文件会明确列出。
- 图库通过本机服务打开，浏览时服务需要保持运行；停止后可以让 Agent 重新打开。
- 界面和分类框架固定，不用于重新设计网站。
- 日常生成只做必要检查；模板改动或异常时再检查受影响功能。

## 仓库内容

仓库包含 Skill 说明、分类与对话规则、生成脚本以及固定网站模板。不包含用户图片、生成的私人图库、测试记录或本机备份。
